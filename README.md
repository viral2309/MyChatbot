# 🤖 MyChatbot

MyChatbot is a simple desktop chatbot application built using Python and Tkinter.

## 🚀 Features

* Greeting responses
* User name interaction
* Date and time
* Programming joke
* Help command
* Calculator
* GUI-based chat interface
* Clear chat button
* Enter key support

## 🛠️ Technologies Used

* Python
* Tkinter
* DateTime

## 📁 Project Structure

```text
MyChatbot/
│
├── chatbot.py
├── chatbot_gui.py
└── README.md
```

## ▶️ How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python chatbot_gui.py
```

5. The MyChatbot application will open.
